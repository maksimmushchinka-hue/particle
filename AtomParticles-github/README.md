# AtomParticles

Плагин для Paper 1.21.11: анимации из частиц.

## Команды

`/atomp <время в секундах> [масштаб] [вид]` — масштаб от 0.1 до 10, по умолчанию 1.
Для эпичных видов время можно не указывать (по умолчанию 60 секунд).

| Вид | Что это |
|---|---|
| `classic` (по умолчанию) | детализированный атом: светящееся ядро, 5 электронов, орбиты, ударные волны |
| `gyro`, `cloud`, `fire`, `ice`, `void` | варианты атома |
| `galaxy`, `storm`, `phoenix`, `portal`, `tree` | эпичные анимации |
| `aurora` | северное сияние |
| `mandala` | мандала света |
| `helix` | двойная спираль (ДНК) |
| `fireworks` | звёздный салют |
| `tesseract` | вращающийся гиперкуб |
| `random` | случайный вид |

- `/atomp loop [масштаб]` — атом по кругу без конца
- `/atomp stop` — остановить свои анимации

Право: `atomp.use` (по умолчанию — операторы).

## Сборка

Java 21 + Maven: `mvn clean package` → `target/AtomParticles.jar` → в папку `plugins/` сервера.
На GitHub jar собирается автоматически (Actions → Build → Artifacts).
